# Practical 4: Express RESTful Task Management API

## Overview
This directory contains an Express.js RESTful API with validation and logging middleware, using in-memory data structures.

## Endpoints
* `GET /tasks` — Get all tasks
* `GET /tasks/:id` — Get task by ID
* `POST /tasks` — Create task
* `PUT /tasks/:id` — Update task
* `DELETE /tasks/:id` — Delete task

## How to Run
```bash
npm install
node server.js
```

## Automated Testing
```bash
node test-api.js
```
