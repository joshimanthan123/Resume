# Practical 6: Full Stack Integration (React + Node.js + Express + MongoDB)

## Project Overview
This directory contains the full-stack Task Management System implementation before authentication was introduced. It connects a React frontend with a Node.js, Express, and MongoDB backend.

## Folder Structure
```text
Practical-6/
├── frontend/    # React 19 + Vite + Tailwind CSS Frontend
├── backend/     # Express.js + MongoDB Backend API
└── README.md
```

## How to Run

### 1. Backend Server
```bash
cd backend
npm install
node server.js
```
Runs on `http://localhost:5000`.

### 2. Frontend Application
```bash
cd frontend
npm install
npm run dev
```
Runs on `http://localhost:5173`.
