# Practical 5: MongoDB & Mongoose Database Integration

## Overview
This directory contains an Express.js RESTful Task API integrated with MongoDB and Mongoose schemas.

## Features
* Mongoose `Task` model schema definition.
* Persistent CRUD operations connected to MongoDB.
* Environment configuration via `.env`.

## How to Run
```bash
npm install
# Ensure MONGO_URI is set in .env
node server.js
```

## Automated Testing
```bash
node test-api.js
```
